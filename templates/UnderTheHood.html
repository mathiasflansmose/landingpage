Under the hood

This website is hosted on a Raspberry Pi!

Next to my router sits a Raspberry Pi hosting this very website. I have set up a Cloudflare tunnel to expose the website, without opening any other ports. The website is built with Flask in a Docker container.

I have always been drawn to infrastructure and DevOps. Instead of using a standard cloud host, I built this to gain hands-on experience with Linux server, secure networking, and continuous deployment.
